- **集中式路由编排**：在 `src/app.js` 中统一定义 API 路径前缀，并通过 `authMiddleware` 和 `roleMiddleware` 实施分层访问控制（如公开查询、管理员导入、超级管理员审计）。
- **全局中间件管道**：请求依次经过 Helmet/CORS 安全层、命名转换（驼峰/下划线互转）、XSS 清洗及参数校验，确保各子模块接收到的数据格式统一且安全。
- **共享数据契约**：所有子模块依赖统一的 `prisma/schema.prisma` 定义的数据模型，通过单例 `PrismaClient` 进行事务性交互，并利用复合索引优化跨表查询性能。
- **标准化响应封装**：通过 `utils/response.js` 和全局错误处理中间件，为各子模块提供一致的 JSON 响应结构（success/message/data）及分页格式。
